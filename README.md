## Featured Projects

### 🚗 [Vehicle Rental System API](https://github.com/mahdimonir/vehicle-rental-system)
> `Node.js` `TypeScript` `PostgreSQL` `Prisma` `JWT` `Swagger` `Vercel`

Production-grade REST API with full Swagger documentation and live deployment.
- JWT authentication with Admin / Customer role-based access control
- Booking overlap detection, auto-return logic, and dynamic cost calculation
- Normalised PostgreSQL schema with Prisma migrations and typed queries
- Every endpoint documented with Swagger/OpenAPI; deployed on Vercel with health monitoring

---

### 🍊 [FruitsZone – ERP System](https://github.com/mahdimonir/fruitszone-erp)
> `Next.js` `TypeScript` `PostgreSQL` `Prisma` `Cloudinary`

Full-scale ERP platform built for multi-tenant business operations.
- Admin and Vendor dashboards with inventory, sales, and order-management workflows
- Real-time stock tracking with automated low-stock alerts
- Granular RBAC applied consistently across all modules without code duplication
- Service-layer architecture enabling fast feature iteration

---

### 🛒 [BD Martify – E-commerce Platform](https://github.com/mahdimonir/bdmartify-nextjs)
> `Next.js` `TypeScript` `MongoDB` `Stripe`

Full-stack e-commerce app with SSR-first architecture.
- Stripe payment integration with order tracking and admin dashboard
- Next.js SSR for SEO-optimised product pages with dynamic category routing

---

### 🩸 [RoktoLagbe – Blood Donation Network](https://github.com/mahdimonir/roktolagbe)
> `Node.js` `TypeScript` `Next.js` `PostgreSQL` `Prisma` `Cloudinary`

Real-time emergency blood request system for rapid donor matching.
- Live donor availability tracking with smart filtering for blood type and location
- Three role-based dashboards (Donor, Manager, Admin) with secure JWT sessions

---

### ✈️ [WestBound Travels – Booking Platform](https://github.com/mahdimonir/west-bound-travels)
> `Node.js` `TypeScript` `Next.js` `PostgreSQL` `Cloudinary` `SSLCommerz`

Travel booking platform with real-time availability and payment integration.
- Optimistic locking at DB level to prevent double-bookings
- SSLCommerz integration with IPN webhook handling and order-state transitions
- Self-serve CMS for admins to manage tours and pricing without developer intervention
